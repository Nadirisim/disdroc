Behind disdroc

Who we are

disdroc is built, operated and funded by nadirisim, an independent developer. It started as a personal project for chatting with friends and now offers servers, messages, voice and shared activities in English and Turkish.

The short version

  • nadirisim — one developer, not a company, no investors.
  • It runs on hardware we own, not a rented cloud.
  • The client source is public on GitHub under AGPL-3.0.
  • The live server implementation is not public. The client source does not verify server operations.

01 One person, not a company

nadirisim develops the app and operates it on owned hardware. You can read the dated release notes, check service status, and use Support to ask a question before creating an account.

This project's source is at github.com/nadirisim/disdroc, and nadirisim's other work is on github.com/nadirisim.

02 Why the client source is public

Publishing the client lets people inspect its code, understand the requests it makes and contribute fixes. The repository contains the web client, desktop wrapper and browser extension. It does not include the live server implementation or private user data.

03 What's public, and what stays closed

The public repository covers the client. Here is the boundary between that code and the hosted service:

Public

The web client, desktop wrapper and browser extension are available in the public repository. The Bot API documentation describes how to build integrations.

Server implementation

The server implementation is not published. Its authentication, storage and moderation behavior cannot be independently checked from the client source alone.

Public source is useful evidence about the client, not a security certification. Read Trust & privacy for message access, data handling, outside providers and service availability.

04 What it's built with

Deliberately small and boring, on purpose — a solo project has to stay maintainable by one person.

Node.js + Express Socket.IO WebRTC voice/video SQLite Vanilla JS frontend llama.cpp (local AI) Runs on owned hardware

Want to look at the code, or report something?

For a normal bug or code contribution, use GitHub. For a private issue or a question before joining, use Support without an account. Do not include passwords or recovery codes in a report.
